## ⚖️ Canonieke regel

1. **Canon-PDF is leidend:** alles in `support/` is wegwijzer; leidend is uitsluitend de PDF in de GitHub Release.
2. **Citatie-eis:** citeer uitsluitend met **sectie (x.x.x)** en een **exacte quote** uit de canon-PDF.
3. **AI-beperking:** output van NotebookLM of andere LLM’s is nooit canoniek en dient alleen als navigatiehulp.


## 🔍 Inhoudelijke toetsing

Voor inhoudelijke toetsing of een tegenargument:

- Inhoudelijke reacties worden uitsluitend behandeld met een **bronanker** (sectie + quote).
- Zonder bronanker is een reactie niet auditbaar.
- Indienen verloopt via het **[Audit-formulier](https://github.com/harriedegroot/zzp-paradox/issues/new?template=audit.yml)**.
